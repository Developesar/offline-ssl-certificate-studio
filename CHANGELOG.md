# Changelog

## 1.0.0 — 2026-10-07

- Initial offline Tkinter certificate converter by mohamadmilad hadad.
- 16 output choices across X.509, PKCS#7, PKCS#12, chains and keys.
- Certificate/key matching, issuer signature checks and duplicate removal.
- Encrypted source keys and password-protected exports; optional legacy PFX compatibility.
- Dark interface, custom icon, in-app format guide, Persian and English documentation.
- Windows standalone executable and synthetic conversion test suite.
